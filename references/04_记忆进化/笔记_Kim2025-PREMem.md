## 一句话总结

**"把推理负担从生成时刻搬到存储时刻"：写入记忆时就把跨会话的推理做掉——抽取事实/经验/主观三类细粒度记忆片段，建立记忆间的显式关系（扩展、转化、蕴含），捕捉演化模式。结果：全模型规模显著提升，小模型的表现可媲美大模型基线，且对 token 预算敏感度低。**

## 摘要（归纳）

会话式 AI 的长期记忆需要**跨会话综合**，但现有系统把过多推理负担压在**回答生成时**，导致性能强依赖模型大小。PREMem 的思路是**在存储（pre-storage）而非生成时做推理**：
1. **细粒度记忆片段抽取**：分为**事实（factual）、经验（experiential）、主观（subjective）**三类信息；
2. **显式记忆关系构建**：跨会话建立记忆项之间的显式关系，捕捉**扩展（extension）、转化（transformation）、蕴含（implication）**等演化模式；
3. **结构**：聚类 → 链接对（link-pair，θ=0.6 阈值）→ 链接对推理，生成富表征后入库存档。
生成时只需做轻量检索 + 生成（低价模型也能胜任）。实验显示**所有规模模型显著提升**，小模型可与大得多基线打平，且即使 token 预算受限仍保持有效。

## 技术路线

```
跨会话对话历史
  ├─① 片段抽取：factual / experiential / subjective 三类细粒度记忆
  ├─② 跨会话链接：聚类 → 构建链接对（相似度阈值 θ=0.6）
  ├─③ 链接对推理（pre-storage）：扩展 / 转化 / 蕴含 → 富化表征
  └─④ 入库（enriched memory repository）
        生成时：轻量检索 + 生成（推理负担小）
```

## 关键结果

| 方面 | 效果 |
|---|---|
| 模型规模 | 各规模模型均显著提升；小模型 ≈ 大模型基线 |
| Token 预算 | 预算受限下仍有效（推理负担已前移） |
| 个性化对话 | 跨会话信息综合/偏好跟踪更一致 |

## 优点 / 局限

- **优点**：把"何时做推理"显式化——写入贵、读取廉，性价比高；三类记忆片段 + 链接对提供可解释的进化轨迹；天然支持跨会话演化综合。
- **局限**：链接对阈值（θ=0.6）与关系类型需调参；片段抽取依赖 LLM 质量；面向对话场景，复杂任务结构化（图谱/程序）记忆未覆盖。
