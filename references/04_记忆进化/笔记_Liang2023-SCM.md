## 一句话总结

**让 LLM"自主控制"自己的记忆：记忆流（memory stream）负责存储，记忆控制器（memory controller）负责"何时写入、何时读取、读什么"，即插即用地给任意指令跟随 LLM 加长程记忆，无需改结构或微调；自标注数据集覆盖长对话/书籍摘要/会议摘要三类任务。**

## 摘要（归纳）

LLM 无法处理超长输入、丢失关键历史信息。SCM（Self-Controlled Memory）框架三大组件：
1. **LLM-based agent**：框架主干（负责推理与生成）；
2. **memory stream**：存储智能体记忆（对话摘要/关键信息）；
3. **memory controller**：**决定何时以及如何**从记忆流中更新/利用记忆（自省式调度：当前是否有足够新信息要写？回答是否需要查记忆？查哪段？）。
无结构修改、无需微调，即可**即插即用**接入任意指令跟随 LLM；自标注数据集评估三类任务：**长程对话、书籍摘要、会议摘要**。相比基线取得更高检索召回率与更信息丰富的回答。

## 技术路线

```
输入 → LLM Agent（主干）
          ▲        │ 生成回答
  读取    │        │ 写入
  ┌───────┴────────▼────────┐
  │     记忆控制器（何时读/写、读什么）│
  └───────┬────────┬────────┘
    memory stream（记忆流：摘要化/关键信息存储）
```

## 关键结果

| 任务 | 效果 |
|---|---|
| 长程对话 | 检索召回率与回答信息量优于基线 |
| 书籍 / 会议摘要 | 超长输入下保持关键信息 |
| 即插即用 | 任意指令跟随 LLM 可直接接入（无需微调） |

## 优点 / 局限

- **优点**：控制器把"何时写、何时读"显式化、可解释；即插即用适配任何 LLM；flash/archived 双记忆分层（短期 flash 联想、长期 archived 归档）。
- **局限**：控制器决策依赖 LLM 自省，规则隐式；记忆流以文本摘要为主，无结构化/图谱；对"主动遗忘/合并去重"未系统展开（侧重读写调度）。
