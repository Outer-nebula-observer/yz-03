## 一句话总结

**"把思考存进记忆"：回答前先 Recalling 召回历史思考，回答后 Post-thinking 把"新的思考"与历史融合写回记忆，用插入/遗忘/合并三种操作让记忆动态进化，再用局部敏感哈希（LSH）实现高效检索——消除"同一历史反复推理产生偏见"的问题。**

## 摘要（归纳）

记忆增强的 LLM 依赖"反复召回历史再推理"，但**同一历史对不同问题的反复推理容易产生偏置思考**（结果不一致）。人类则把思考本身存入记忆、无需反复推理。TiM：
1. **Recalling（前向）**：生成回答前，从外部记忆检索与当前上下文相关的历史思考；
2. **Post-thinking（后向）**：回答生成后，将新旧思考整合、把思考结果写入记忆；
3. **记忆组织三原则/操作**：**插入（insert）、遗忘（forget）、合并（merge）**，支撑记忆动态更新与进化；时间衰减用于遗忘；
4. **LSH 检索**：局部敏感哈希实现长程对话的高效检索。
真实与模拟会话（覆盖面广）的定性与定量实验表明，TiM 显著提升 LLM 长程交互中的回答质量。

## 技术路线

```
对话流
 ├─① Recalling：LSH 检索相关历史思考（前向）
 ├─② 生成回答（结合历史思考 + 当前问题）
 ├─③ Post-thinking：整合新旧思考，生成更新后的思考
 └─④ 记忆更新：插入新思考 / 合并相似 / 遗忘过时（时间衰减）
      └─ 循环
```

## 关键结果

| 方面 | 效果 |
|---|---|
| 长程对话 | 回答质量显著优于反复推理的基线（减少偏置） |
| 记忆进化 | insert/forget/merge 三操作令记忆动态演化，不无限膨胀 |
| 效率 | LSH 检索支撑长程高效召回 |

## 优点 / 局限

- **优点**：首次明确"思考入记忆"范式；插入/遗忘/合并三操作与认知记忆操作精确对应；检索用 LSH 保效率；闭环设计与赛题架构几乎一一映射。
- **局限**：遗忘采用简单时间衰减，重要性打分弱；记忆以文本思考为主，结构化/多模态支持有限；合并策略依赖规则/LLM 判断，冲突消解未深入。
