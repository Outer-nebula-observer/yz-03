## 一句话总结

**面向"长期陪伴"场景的 LLM 长期记忆机制：用「每日高级摘要 + 用户画像洞察」持续进化记忆，用受艾宾浩斯遗忘曲线启发的更新机制模拟人类"选择性遗忘"，落地为长期 AI 陪伴机器人 SiliconFriend——能共情、能召回相关记忆、能理解用户性格。**

## 摘要（归纳）

LLM 缺乏长期记忆，在持续交互场景（陪伴机器人、心理咨询、秘书助理）中表现不佳。MemoryBank 提供：
1. **记忆召唤（summon）**：按需求召回相关历史记忆；
2. **记忆更新（update）**：受**艾宾浩斯遗忘曲线**启发，根据**时间流逝 + 记忆相对重要性**决定遗忘/强化（reinforce），模拟人类记忆的"选择性保留"；
3. **持续理解与进化**：长期交互中不断提炼**高等级每日摘要**与**用户画像洞察**，随时间适应并理解用户性格。
兼容闭源（ChatGPT）与开源（ChatGLM）模型，落地为长期 AI 陪伴聊天机器人 **SiliconFriend**（用心理对话数据微调，提升共情与洞察）。评测含真实用户对话的定性分析 + ChatGPT 扮演多类用户的模拟对话定量分析。

## 技术路线

```
用户对话流
  └─① 对话记忆更新（艾宾浩斯遗忘曲线：
       遗忘程度 ∝ 时间流逝、∝ 1/重要性；命中则强化）
  └─② 高级摘要（每日/阶段性对话 → 高等级摘要）
  └─③ 用户画像洞察（长期数据综合 → 性格/偏好洞察）
        ↓
  记忆库（可检索）→ 回答时召回相关记忆 → 生成共情、一致的回答
```

## 关键结果

| 方面 | 效果 |
|---|---|
| 长期陪伴 | SiliconFriend 能召回相关记忆、理解用户性格、给出共情回答 |
| 记忆系统 | 遗忘曲线机制比"全存/全忘"更接近人类、检索更聚焦 |
| 模型兼容 | ChatGPT（闭源）与 ChatGLM（开源）均可接入 |

## 优点 / 局限

- **优点**：首次把艾宾浩斯遗忘曲线引入 LLM 记忆更新——"遗忘"有了心理学依据；摘要 + 画像两档抽象层次清晰；可配闭源/开源模型。
- **局限**：遗忘策略是**手工规则**（时间衰减+重要性），非学习式；检索以关键词/简单语义为主，未做向量检索评测；面向单用户陪伴场景，多任务/复杂推理场景覆盖有限。
