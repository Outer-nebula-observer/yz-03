## 一句话总结

**面向开放世界游戏的"角色扮演语言智能体"认知架构：把长期记忆分为「角色设定记忆 + 情景/场景记忆 + 常识记忆」三类分域存储，配合反馈驱动的可学习动作空间与人格对齐后处理，让 agent 在长时间开放世界模拟中保持角色一致性与连贯行为。**

## 摘要（归纳）

语言 agent 在限定场景、短时间线内表现出色，但开放世界模拟要求**长期记忆保持连贯行为**。LARP 提出角色扮演语言智能体框架，包含：
1. **认知架构**：记忆处理（三类记忆分域） + 决策辅助（经验辅助动作决策）；
2. **环境交互模块**：反馈驱动的**可学习动作空间**（agent 从交互反馈中学习可用动作/技能）；
3. **后处理方法**：对齐不同性格/人设（personality alignment）。
框架强化了用户与具备独特背景与人设的 agent 之间的交互，提升开放世界游戏体验，展示了语言模型在娱乐、教育、仿真等领域的多用途。

## 技术路线

```
┌─ 记忆处理（三类分域长期记忆）───────────┐
│ ① 角色设定记忆（性格/背景/目标——低频稳定） │
│ ② 情景/场景记忆（环境状态、事件——动态）    │
│ ③ 常识记忆（世界知识）                    │
└───────────────┬───────────────────────┘
                │ 检索（按当前情境取相关记忆）
┌───────────────▼───────────────────────┐
│ 决策辅助：记忆 + 可学习动作空间 → 动作选择  │
└───────────────┬───────────────────────┘
                │ 环境执行 → 反馈
                ▼
  可学习动作空间更新（动作可行性/收益学习）
  + 人格对齐后处理（输出贴合人设）
```

## 关键结果

| 方面 | 效果 |
|---|---|
| 长程一致性 | 开放世界长时间交互中角色行为保持一致（烧钱/知识冲突减少） |
| 动作学习 | 反馈驱动的动作空间让 agent 学会环境允许的动作集合 |
| 人格对齐 | 不同性格 agent 输出风格可区分、稳定 |

## 优点 / 局限

- **优点**：把长期记忆按"稳定度/语义"分域（角色/情景/常识），分层清晰；人设对齐对"角色一致性"场景可直接借鉴。
- **局限**：主要面向游戏娱乐场景；记忆分域偏概念化，检索/遗忘机制细节少；评测以定性 + 场景内指标为主，缺少标准化 benchmark。

## 与赛题③的联系

| 借鉴点 | 说明 |
|---|---|
| 三域记忆划分 | 赛题长期记忆可类比：作战条令/装备参数（稳定事实） vs 场次态势（情景） vs 领域知识（常识） |
| 角色一致性 ↔ 规划风格一致 | 指挥风格/决策偏好作为"角色记忆"常驻，防止同一情景不同场次规划风格漂移 |
| 可学习动作空间 | 对应"经验→可执行策略"的沉淀（与 Memp 程序记忆呼应） |
