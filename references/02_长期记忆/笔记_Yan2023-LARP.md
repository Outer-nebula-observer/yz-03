# 论文精读（深化版）：LARP — Language-Agent Role Play for Open-World Games

> - **作者 / 机构**：Ming Yan、Ruihao Li、Hao Zhang 等（MiAO）
> - **发表**：arXiv 2023（2312.17653）
> - **对应**：`references/02_长期记忆/Yan2023-LARP.pdf` → 同名 `.md`
> - **项目主页**：https://miao-ai-lab.github.io/LARP/

## 一句话总结

面向开放世界游戏的"角色扮演语言智能体"认知架构：四模块（长期记忆/工作记忆/记忆处理/决策）+ 长期记忆按认知科学分 declarative（语义+情景）与 procedural 三类分域存储 + 反馈驱动可学习动作空间 + 人格对齐后处理。

## 1. 认知架构（四模块循环）

```
┌─ 长期记忆（LTM，大容量仓库）─────────────────┐
│  declarative：语义记忆 + 情景记忆              │
│  procedural：动作/技能（API 形式）             │
└───────────────┬──────────────────────────────┘
                ▼
┌─ 记忆处理（encoding → storage → recall）──────┐
│  把 LTM 信息 + 观察 加工后传入工作记忆           │
└───────────────┬──────────────────────────────┘
                ▼
┌─ 工作记忆（临时缓存，容量有限）─────────────────┐
└───────────────┬──────────────────────────────┘
                ▼
┌─ 决策模块：工作记忆 + 观察 → 动作/对话           ┐
└────────────────────────────────────────────────┘
```

## 2. 长期记忆三类分域（对齐认知科学）

| 记忆类型 | LARP 实现 | 特点 |
|---|---|---|
| **语义记忆**（世界知识/规则/世界观） | 外部数据库（稳定不常变部分）+ 符号语言存 LTM 模块（部分） | 稳定事实走结构化外部 DB |
| **情景记忆**（具体经历事件） | 向量数据库存储检索 + **衰减参数**（相关性分数随时间降） | 向量查询召回，带时间衰减 |
| **程序性记忆**（动作/技能） | API 形式存动作空间；分 **public APIs + personal APIs** | personal APIs 可通过学习扩展 |

> 双视角锚定 + 人格对齐后处理：让输出贴合角色人设，维持长程一致性。

## 3. 关键结果

| 方面 | 效果 |
|---|---|
| 长程一致性 | 开放世界长时间交互中角色行为保持一致（冲突减少） |
| 动作学习 | 反馈驱动动作空间让 agent 学会环境允许的动作集合 |
| 人格对齐 | 不同性格 agent 输出风格可区分、稳定 |

## 5. 优点 / 局限（深化）

- **优点**：把长期记忆按"稳定度/语义"分域（语义/情景/程序），分层清晰且对齐认知科学；情景记忆带时间衰减参数；人设对齐对角色一致性可直接借鉴；程序性记忆以 API + 可扩展 personal API 落地。
- **局限**：主要面向游戏娱乐；记忆分域偏概念化，检索/遗忘机制细节少；评测以定性 + 场景内指标为主，缺标准化 benchmark；无公开代码。

## 6. 与赛题③的联系（深化）

| 借鉴点 | 落地 |
|---|---|
| 三域记忆划分 | 赛题长期记忆类比：作战条令/装备参数（稳定事实）vs 场次态势（情景）vs 领域知识（常识） |
| 角色一致性 ↔ 规划风格一致 | 指挥风格/决策偏好作"角色记忆"常驻，防同情景不同场次规划风格漂移 |
| 可学习动作空间（personal API 扩展） | 对应"经验→可执行策略"沉淀（与 Memp 程序记忆呼应） |
| 情景记忆时间衰减 | 遗忘机制的另一佐证（与 MemoryBank 艾宾浩斯呼应） |
