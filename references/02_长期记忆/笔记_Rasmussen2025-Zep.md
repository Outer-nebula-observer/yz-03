## 一句话总结

**把 agent 记忆做成"时序知识图谱（Temporal Knowledge Graph）"：Graphiti 引擎把非结构化对话与结构化业务数据动态合成为带时间属性的实体-关系图谱，在 DMR 基准上超过 MemGPT（94.8% vs 93.4%），在更贴近企业场景的 LongMemEval 上准确率最高提升 18.5%、延迟降低 90%。**

## 摘要（归纳）

现有 RAG 框架只支持**静态文档检索**，而企业应用需要从**持续对话 + 业务数据**中动态整合知识并保持历史关系。Zep 通过核心组件 **Graphiti**——一个**时间感知知识图谱引擎**解决该问题：
- 动态合成非结构化会话数据与结构化业务数据；
- **始终维护历史关系**（图谱带时间轴，可回放"当时的关系"）；
- 支持复杂时序推理（跨会话信息综合、长期上下文维护）。
评测：DMR 基准 94.8% vs MemGPT 93.4%；LongMemEval（更接近企业用例）准确率最高提升 18.5%、响应延迟降低 90%。

## 技术路线

```
对话/业务数据流入
  ├─① 增量图构建：抽取实体/关系，写入带时间戳的知识图谱
  ├─② 时序维护：边带 valid-time/发生顺序，保留历史语义
  ├─③ 图谱检索：根据查询做子图召回（结合语义+结构+时间）
  └─④ 返回给 LLM：图谱摘要/子图文本 → 支持时序问答与跨会话综合
```

## 关键结果

| 基准 | Zep | 对比 |
|---|---|---|
| DMR（MemGPT 提出的深度记忆检索） | 94.8% | MemGPT 93.4% |
| LongMemEval（企业时序推理） | 准确率最高 +18.5%、延迟 -90% | 优于 RAG 基线实现 |

## 优点 / 局限

- **优点**：图谱天然支持多跳、跨会话、时序推理；结构化事实可精确召回（对齐赛题"事实记忆 精确召回"验证点）；有开源引擎可直接二次开发。
- **局限**：图谱构建依赖 LLM 抽取质量，错抽/漏抽会污染关系；增量图更新与版本管理复杂；纯文本/简单场景下比向量库方案重。
