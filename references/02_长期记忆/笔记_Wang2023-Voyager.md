## 一句话总结

首个 LLM 驱动的终身学习具身 agent：在 Minecraft 中靠 GPT-4 黑盒查询，用「**自动课程 + 可执行代码技能库 + 迭代提示（环境反馈/报错/自验证）**」无人工干预持续探索——技能可组合复用、缓解灾难性遗忘，3.3× 更多物品、2.3× 更远行程、科技树快 15.3×。

## 1. 三大组件

| 组件 | 作用 |
|---|---|
| 自动课程（Automatic Curriculum） | GPT-4 据探索进度+当前状态自下而上提议新任务，保"挑战但可管理" |
| 技能库（Skill Library） | 每技能=一段可执行代码，按描述 embedding 入向量库，可检索复用 |
| 迭代提示机制 | 融合环境反馈/执行报错/自验证，迭代改进代码 |

## 2. 技术路线（深化）

```
┌─① 自动课程（GPT-4 提议任务）─────────────────────────┐
│  输入：①多样性指令 + 约束 ②agent 当前状态（背包/装备/附近方块/生物群系/时间/生命饥饿/位置） │
│        ③已完成/失败任务（能力前沿）④GPT-3.5 自问自答补充上下文              │
│  输出：下一个适合任务（如"挖钻石"）                          │
└──┬──────────────────────────────────────────────────┘
   ▼
┌─② 技能库（向量数据库）──────────────────────────────┐
│  新增：GPT-4 生成 + 验证通过的技能 → key=描述 embedding（GPT-3.5 生成）│
│        value=程序代码本身；按描述 embedding 索引              │
│  检索：新任务来 → GPT-3.5 生成解题建议 + 环境反馈 → 查询 top-5 相关技能  │
└──┬──────────────────────────────────────────────────┘
   ▼
┌─③ 迭代提示（生成 + 自改进）──────────────────────────┐
│  GPT-4 输入：①代码生成指南 ②控制原语 API + 检索到的相关技能（ICL）   │
│             ③上一轮代码 + 环境反馈 + 执行报错 + 批评 ④当前状态 ⑤CoT     │
│  迭代至通过自验证 → 入技能库                              │
└──────────────────────────────────────────────────────┘
```

**关键设计**：技能用**可执行代码**（非文本经验）——具时间延续性、可解释、可组合，复利增强并缓解灾难性遗忘；GPT-3.5 做标准 NLP 任务省预算，GPT-4 做核心推理。

## 5. 优点 / 局限（深化）

- **优点**：技能=可执行可组合可迁移程序（非模糊文本经验）；自动课程解"学什么"；无需微调；代码技能规避语言经验不精确性；复利增强且防灾难性遗忘。
- **局限**：面向 Minecraft 类具身环境，与 NLP 对话/规划差异大；提示循环依赖 GPT-4 级模型；技能库无显式遗忘/合并管理，规模增长后检索质量待考证；评测以游戏内指标为主。

## 我们的实现（memsys）

- **思路**：技能库的"描述向量↔可执行本体"双记录结构 → 我们的经验库"教训文本↔metadata（含程序性字段）"；自动课程暂不实现（作战任务由场次给定）；
- **代码索引**：`memsys/long_term/experiential_store.py::add()`——`vindex.add(entry.id, f"{content}\n{source}")` 内容+来源联合编码（提高情境相似召回）。

## 代码详解（技能库式双记录 → 经验库的编码策略）

```python
# experiential_store.py::add()（节选）
def add(self, entry):
    self._entries[entry.id] = entry
    # 关键：向量编码 = 教训正文 + 来源场次（"教训：夜战…伏击" + "复盘:P001"）
    # 对应 Voyager 的"描述 embedding"：描述含情境（何时何地学的），
    # 相似情境的新任务才能召回这条技能
    self.vindex.add(entry.id, f"{entry.content}\n{entry.source}")
```
> 差异：Voyager 的 value 是可执行代码（直接调用）；我们的 value 是结构化文本教训（进阶可把"对策"字段升级为可执行预案——Memp 程序记忆路线）。
