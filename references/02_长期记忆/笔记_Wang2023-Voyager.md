## 一句话总结

**第一个"LLM 驱动的终身学习具身智能体"：在 Minecraft 中靠 GPT-4 黑盒查询，用「自动课程 + 可增长技能库（可执行代码）+ 迭代提示（环境反馈/报错/自验证）」无人工干预地持续探索——技能可组合复用、缓解灾难性遗忘，3.3× 更多物品、2.3× 更远行程、科技树解锁快 15.3×。**

## 摘要（归纳）

Voyager 是首个由 LLM 驱动的、可在 Minecraft 中**持续探索、习得多种技能、做出新发现**且**无需人工干预**的终身学习智能体，包含三大组件：
1. **自动课程（Automatic Curriculum）**：根据当前技能掌握情况最大化探索（选下一个"适合学"的任务，类似课程学习）；
2. **不断增长的技能库（Skill Library）**：用**可执行代码存储与检索**复杂行为（每个技能=一段可复用程序，具时间延续性、可解释、可组合）；
3. **迭代提示机制（Iterative Prompting）**：融合**环境反馈、执行报错、自验证**来改进程序。
与 GPT-4 通过黑盒查询交互，**无需微调参数**。技能随时间延续、可解释、可组合，快速复利增强能力并**缓解灾难性遗忘**。相比当时 SOTA：获得 **3.3×** 更多独特物品、行进距离 **2.3×** 更长、解锁关键科技树里程碑快 **15.3×**；且能在**全新 Minecraft 世界**中利用已有技能库从零解决新任务（基线难以泛化）。

## 技术路线

```
┌─ 自动课程：依据现有技能 → 选择下一个探索任务（exploration 最大化）
├─ 技能库（可增长）：<任务描述, 可执行代码>，按语义检索复用
├─ 迭代提示机制：
│    生成代码 → 环境执行 → 反馈/报错/自验证 → 修改代码（循环至通过）
└─ 与 GPT-4 黑盒交互（无微调）
```

## 优点 / 局限

- **优点**：技能库是可执行、可组合、跨世界迁移的程序（不只是文本经验）；自动课程解决"学什么"；无需微调；用代码技能规避了语言经验的不精确性。
- **局限**：技能面向 Minecraft 类具身环境，与 NLP 对话/规划场景差异大；提示循环依赖 GPT-4 级模型能力；技能库无显式遗忘/合并管理，规模增长后检索质量待考证。
