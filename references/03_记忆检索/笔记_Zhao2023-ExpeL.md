## 一句话总结

**"体验式学习"agent：不微调参数，而是让 agent 在一批训练任务上自主积累轨迹，用自然语言提炼经验（成功/失败模式），推理时从 Faiss 向量库召回相似成功轨迹与提炼经验辅助决策——性能随经验积累持续提升，且具备涌现能力与迁移能力。**

## 摘要（归纳）

对决策任务微调 LLM 资源密集、可能损害泛化，且 GPT-4/Claude 权重封闭不可微调。ExpeL（Experiential Learning）agent 完全在**推理时学习**：
1. **经验收集**：在训练任务集上自主执行，保存**完整轨迹**（成功与失败）；
2. **知识提炼**：用自然语言从轨迹中提取**经验教训/成功模式**（对比成败轨迹，识别可复用策略）；
3. **推理时召回**：新任务到来，从 Faiss 向量库召回**相似的成功轨迹**与**提炼的经验**，注入 prompt 辅助决策。
实验表明性能随经验积累**一致提升**；还观察到涌现能力（跨任务泛化、类比迁移）。

## 技术路线

```
训练任务集
  └─① 经验收集：agent 执行任务，保存完整轨迹（成功/失败）
       └─② 知识提炼：对比成败 → 自然语言经验集（模式/教训）
            └─③ 经验库（Faiss 向量库：成功轨迹 + 提炼经验）
                 └─④ 推理时：新任务 → 检索 Top-K 相似轨迹/经验 → 注入上下文 → 决策
```

## 关键结果

| 环境 | 效果 |
|---|---|
| ALFWorld / WebShop / 与 ReAct 对比 | 随经验积累成功率持续提升，显著超过 ReAct/Act 等基线 |
| 通用决策（环境交互任务） | 表现可媲美需要微调的方法 |
| 涌现与迁移 | 观察到跨任务经验复用与类比迁移能力 |

## 优点 / 局限

- **优点**：免微调、"越用越强"；经验提炼为可读文本，可解释；检索加提炼两段式召回质量高。
- **局限**：经验提炼依赖 LLM 归纳能力；向量检索对"任务相似度"敏感，相似任务差距大时召回质量下降；经验库无遗忘/更新机制，长期会积累过时经验（对新方案演进不敏感）。
