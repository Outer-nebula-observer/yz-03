## 3. 记忆形式权衡（综述核心，组会必引）

| 维度 | 文本记忆 | 参数记忆 |
|---|---|---|
| 写入效率 | ✅ 高（直接写文本） | ❌ 低（需训练/编辑） |
| 读取效率 | ❌ 低（塞上下文，成本随长度增） | ✅ 高（隐式影响行为） |
| 可解释性 | ✅ 强（自然语言） | ❌ 弱（潜空间） |
| 信息密度 | ❌ 低（离散 token） | ✅ 高（连续表征） |
| 适用 | 对话/上下文/可解释 | 大规模知识/既定知识库 |

> 赛题③选**文本记忆**（可演示、可溯源、可量化进化）。

## 5. 进化操作对照（赛题"写/合并/遗忘/抽象"文献依据）

| 操作 | 实现 | 代表 |
|---|---|---|
| 合并去重 | 相似同组 / 链接对 θ=0.6 / Add⊖Del⊕Update | TiM / PREMem / Memp |
| 反思抽象 | 语言反思 / Post-thinking / 事件触发反思 / 周期语义整合 | Reflexion / TiM / Generative Agents / StructMem |
| 遗忘 | 艾宾浩斯 R=e^(-t/S) / 时间衰减 / 命中强化 | MemoryBank / TiM |
| 程序化 | 可执行代码技能库 / Build-Retrieve-Update | Voyager / Memp |
| 可学习操作 | INSERT/UPDATE/DELETE/SKIP 可进化技能 / RL | MemSkill / Mem-α |
| 更新纪律 | 持续更新/纠正/弃用 | Memp / Zep 图谱增量 |

**三条进化技术路线（演进故事）**：
1. 规则/操作驱动（2023）：TiM 三操作 + 时间衰减、MemoryBank 艾宾浩斯；
2. 控制器/结构化驱动（2023–2025）：SCM 控制器、StructMem 分层整合；
3. 预存储推理/可学习操作（2025）：PREMem 前移推理、Mem-α/MemSkill 可学习操作。

## 7. 赛题③选型速查（按模块：首选/进阶/对照）
