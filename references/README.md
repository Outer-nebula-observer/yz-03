## 一键下载论文 PDF

在仓库根目录运行（仅用 Python 标准库，无需安装依赖）：

```bash
python scripts/download_papers.py            # 下载全部论文到对应模块目录
python scripts/download_papers.py --dry-run  # 只打印清单，不联网
```

- 大部分论文用固定 arXiv 编号直接下载；
- 脚本会**优先走国内镜像** `xxx.itp.ac.cn` / `cn.arxiv.org`，直连 arxiv 被重置（WinError 10054）时一般能成功；
- RMM / StructMem / MemSkill 无固定编号，脚本会按标题走 arXiv API 自动检索；
- 下载失败的条目脚本会汇总列出，可按各子目录 README 里的链接手动下载。

## 论文提取与精读（已固化）

```
一键提取（PDF → Markdown 全文，pymupdf4llm）：
    python scripts/pdf2md.py --all        # 批量提取 references 下所有 PDF
    python scripts/pdf2md.py <pdf路径>     # 提取单篇
    # 若无 pymupdf4llm，可复用调研工作区 venv：
    #   "C:/Users/20784/Desktop/调研工作区/.venv/Scripts/python.exe" scripts/pdf2md.py --all
```

- **全文提取**：每个 PDF 同目录生成 `<同名>.md`（完整全文，供精读/检索）；
- **精读笔记**：同目录 `笔记_<论文名>.md`，统一结构＝一句话总结 / 摘要 / 技术路线 / 关键设计 / 实验结果 / 代码索引 / 优缺点 / 与赛题③的联系；
- **组会汇报综述**：见 [组会汇报_模型记忆体系综述.md](./组会汇报_模型记忆体系综述.md)（模型记忆分类 + 操作/进化梳理 + 15 篇论文索引 + 汇报结构建议）。

## 放置约定

- 下载的论文 PDF 放入对应模块子目录，命名由脚本统一生成 `<一作><年份>-<短标题>.pdf`；
- 每个子目录的 `README.md` 已列出该模块核心论文清单（题目、arXiv、一句话要点、代码位置）；
- 论文精读笔记在本目录对应模块下 `<论文名>-笔记.md`（即 `笔记_*.md`），全文提取为同名 `.md`。
