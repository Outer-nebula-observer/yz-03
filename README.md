# 研究生实践课程《课程总体设计》— YZ-03 团队仓库

> **课程名称**：异构多模态数据环境下大模型作战规划智能体记忆系统构建
> **基础平台**：「智戎」大小模型协同作战规划系统
> **当前选题**：**赛题③（长短期记忆系统）**

本仓库用于团队协作，归档课程资料、参考文献、方案文档与开发代码。

---

## 目录结构

| 目录 | 用途 | 说明 |
|---|---|---|
| `code/` | **实际开发代码（顶层）** | 老师下发的「记忆检索引擎 SDK」+ 我们赛题③的实现 |
| `docs/` | 方案与笔记文档 | 赛题分析、各赛题方案、讲义整理、Git 协作指南 |
| `references/` | 课题三参考文献（按模块） | 00 综述 / 01 短期 / 02 长期 / 03 检索 / 04 进化 / 05 评估 |
| `course_materials/` | 课程 PPT 原始资料 | 老师 PPT、讲义 PDF、提取产物 |
| `paper_code/` | 论文公开代码（参考复现） | 与 `code/` 区分：这里放**别人论文**的代码 |

---

## 快速开始

1. **了解课程与选题** → `docs/01_赛题分析与选题推荐.md`
2. **掌握记忆理论/论文** → `docs/03_长短期记忆与记忆评估讲义整理.md`
3. **开始赛题③开发** → `docs/04_赛题三长短期记忆系统完整方案.md`
4. **开发代码入口** → `code/README.md`，先读 `code/记忆检索引擎SDK/README.md`
5. **Git 协作** → `docs/git协作指南.md`

---

## 协作约定

- 提交注释规范见 `docs/git协作指南.md`（**参考模板，不强制、不拦截**）；
- 单个文件超过 100MB 请用 Git LFS（本仓库 pptx/pdf 已在限额内）；
- 不要提交密钥、`.env`、模型权重、训练数据；
- 每人改自己分工的文件，先 `pull` 再提交，减少冲突。
