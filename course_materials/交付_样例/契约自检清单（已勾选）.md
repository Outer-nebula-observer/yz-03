## 契约合规

- [x] `engine_plugin` 是 `MemoryEnginePlugin` 实例 —— `server/engines/command_graph/__init__.py` 导出模块级 `engine_plugin`
- [x] `name` 唯一，小写下划线 —— `command_graph`
- [x] `engine_label` 非空 —— `指挥决策图谱`
- [x] `engine_color` 是 `#rrggbb` —— `#2f6fd0`
- [x] `contract_version == "1.0.0"`
- [x] `capabilities` 与已实现方法一致 —— 只声明检索能力：`supports_ingest=False`、`supports_delete=False`、`supports_generate=False`、`supports_stream=False`、`supports_browse=False`；未实现的 ingest/generate 方法一律未声明（`validate_plugin` 无违规）

## 检索结果（search）

- [x] 每条返回 `content` / `score` / `source_file` / `chunk_id` / `engine` 五字段（另附 `metadata`）
- [x] `score` 归一化 0~1 —— 实测 5 题、每题 8 条，区间 0.50~0.96，无越界
- [x] `source_file` 是「检索数据根」相对路径（正斜杠）—— 取值仅 `知识图谱数据/TIAOLING_CN`、`知识图谱数据/ZUOZHAN_CN`，无系统绝对路径

## 运行约束

- [x] 无同步 IO / 重计算阻塞事件循环 —— 文件读取（`pd.read_parquet` 等）全部走 `asyncio.to_thread`
- [x] 不吞异常返回空列表 —— 检索异常向上抛，交路由器熔断器；仅「无可用数据源」时返回空列表并记 WARNING
- [x] `check_availability` 带 TTL —— `AVAILABILITY_TTL = 60.0` 秒

## 生成（本引擎不支持，故不适用）

- [x] `supports_generate=False` / `supports_stream=False` —— 不实现 `generate` / `generate_stream`；
      服务端 SSE 层按契约自动补 `engine_done(status="unsupported")`，插件无需发事件
