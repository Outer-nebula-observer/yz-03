# 记忆引擎接入自检清单

交付前逐项勾选，全部通过再交给集成方。

## 契约合规
- [ ] `engine_plugin` 是 `MemoryEnginePlugin` 实例
- [ ] `name` 唯一，小写下划线（`[a-z][a-z0-9_]*`）
- [ ] `engine_label` 非空
- [ ] `engine_color` 是 `#rrggbb`
- [ ] `contract_version == "1.0.0"`
- [ ] `capabilities` 与已实现方法一致（`supports_X=True` 就必须实现对应方法）

## 检索结果（search）
- [ ] 每条返回 `content` / `score` / `source_file` / `chunk_id` / `engine` 五字段
- [ ] `score` 归一化 0~1
- [ ] `source_file` 是「检索数据根」相对路径（正斜杠），非系统绝对路径

## 运行约束
- [ ] 无同步 IO / 重计算阻塞事件循环（用 `asyncio.to_thread`）
- [ ] 不吞异常返回空列表（让异常抛出，由路由器熔断器接管）
- [ ] `check_availability` 带 TTL（如 60s），避免永久缓存探测结果

## 生成（若 supports_generate / supports_stream = True）
- [ ] `generate_stream` 恰好发射一个 `engine_done`
- [ ] `engine_done` payload 含 engine / engine_label / engine_color / status / generated_text / citations / sources / elapsed_ms / retrieval_count
- [ ] payload JSON 单行序列化

## 验证
- [ ] `python scripts/validate_engine.py <引擎名>` 通过（退出码 0）
- [ ] `python scripts/smoke_test_engine.py <引擎名>` 引擎已注册且有检索结果
- [ ] `GET /api/v2/memory-engine/engines` 能看到该引擎
