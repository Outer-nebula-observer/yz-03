## 二、接入正式系统①：老师 SDK 检索服务（memory_engine_sdk.md 衔接）

### 2.1 我们的引擎怎么长在 SDK 上

`code/课题3_长短期记忆/engine.py` 的 `LongShortTermMemoryEngine` 完整实现
`MemoryEnginePlugin` 契约（§3.1）。**四步接入**（详见 `sdk_check.py` 头注释）：

```
1. 拷贝 课题3_长短期记忆/ 整个目录 → SDK 服务的 server/engines/ 下
2. 重启服务 → discover_plugins() 自动发现 __init__.py 的 engine_plugin
   （name: long_short_term_memory；前端出现「长短期记忆」引擎）
3. 契约自检：
   python -c "from server.engines.memory_plugin_api import validate_plugin; \
              from server.engines.课题3_长短期记忆 import engine_plugin; \
              print(validate_plugin(engine_plugin))"    # 期望输出 []
4. HTTP 冒烟：SDK 的 scripts/smoke_test_engine.py 或前端选「长短期记忆」实测
```

### 2.2 契约合规要点（已逐条对齐，sdk_check.py 18 项断言锁定）

| SDK 契约条款 | 我们的实现 | 状态 |
|---|---|---|
| §3.1 元数据七项（name/label/color/version/…） | 类属性齐备，`#2E86AB` 等格式合规 | ✅ |
| §3.2 score 归一化 0~1 | 融合分 ÷ (α+β+γ) 再截断（§9 陷阱 4） | ✅ |
| §3.2 source_file 非绝对路径 | 用条目 source（"复盘:P001"/"seed" 等可辨识标记） | ✅ |
| §3.3 不与内建引擎争后缀 | `supported_suffixes=[]`（.txt 已被 standard_rag 认领） | ✅ |
| §3.4 不支持生成 | `supports_generate/stream=False`，SSE 层自动发 unsupported | ✅ |
| §6.3 保留名黑名单 | name=long_short_term_memory 不冲突 | ✅ |
| §9 陷阱 1 同步 IO 阻塞 | `asyncio.to_thread(self._search_sync, ...)` | ✅ |

### 2.3 权重/超时配置（SDK §7）

接入后可在 SDK 的 `config.json` 调我们的融合权重参与全局排序：

## 三、接入正式系统②：智戎规划链路（三挂接点）

### 3.1 挂接点设计（integration/zhirong_adapter.py）

| 挂接点 | 智戎管线时机 | 我们做什么 | 返回 |
|---|---|---|---|
| `hook_plan(plan_id, goal, constraints)` | 规划启动前 | ①②③④ 建槽位→查询列表→检索→装载 | `{"context": 记忆增强上下文, "retrieved": N, "elapsed_ms"}` |
| `hook_feedback(text)` | AFSIM 推演后 | ⑥ 暂存反馈（close 时并入复盘） | `{"ok", "elapsed_ms"}` |
| `hook_close(extra_review)` | 场次结束 | ⑦ 复盘进化（四操作+边界门控） | `{"write/merge/forget/abstract", "boundary", "elapsed_ms"}` |

**智戎侧只需三行代码**：
```python
adapter = ZhirongAdapter()                                  # 初始化（可注入真模型）
ctx = adapter.hook_plan("ZR-001", "夜间夺占2号高地", ["禁止越境"])["context"]
# ... 智戎自身规划管线执行（ctx 作为 prompt 增强部分）...
adapter.hook_feedback("推演：任务部分达成。教训：…")            # AFSIM 结果文本化
report = adapter.hook_close()                                # 自动沉淀经验
```

### 3.2 验收级工程保障（tests 用例 11 锁定）

- **时延记录**：每挂接点 wall-clock 毫秒；`IntegrationLog.summary()` 输出
  per-hook `calls/avg_ms/max_ms` —— 验收材料即 `to_dict()`（JSON 可直接归档）；
- **异常降级**：检索层故障时 `hook_plan` 返回空上下文**而非抛出**
  （记忆系统故障不阻断作战规划——军规级可用性要求），失败记入日志可观测；
- **mock 全链路**：`python integration/zhirong_adapter.py` 一条命令演示
  完整一场（预置记忆→规划前增强→反馈→进化→时延汇总）。
