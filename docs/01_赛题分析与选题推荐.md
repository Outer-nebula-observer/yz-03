# 第一部分：PPT 整理与四赛题分析

## 0. 课程总体概览

**课程名称**：异构多模态数据环境下大模型作战规划智能体记忆系统构建

**基础平台**：「智戎」大小模型协同作战规划系统

**核心目标**：以 LLM 为核心，连接专业算法技能，读取规划知识库，实现 AFSIM 对抗推演闭环；探索智能体记忆技术，提高智能体知识利用质效，使规划结果更加可靠可信。

**系统主链路**：

```
指挥员(决策主体)
   │ 自然语言意图
   ▼
LLM 认知协调者（意图理解·任务分解·流程编排·调度）
   │ 流程驱动
   ▼
规划管线（启动→分析→生成→分析→比较→批准→指令）
   │ 知识锚定（只许用库里的数据）
   ▼
规划知识库 ──────────────► 专业技能池（50+原子计算技能，精确计算结果）
   │                              │
   └──────────────────────────────┴──► AFSIM 对抗推演
```

**三个核心痛点（为什么要做记忆系统）**：

1. 模型本身**记不住**（上下文有限）；
2. 模型**装不下**（知识海量且多模态）；
3. 模型**会编**（幻觉），所以记忆必须**外置成系统**。

**记忆系统的定义**：持久化、可检索、可更新的知识与状态存储。

**战场知识原材料的特点**：表格、文档、PDF、图片混杂——不是一个整整齐齐的数据库。

**课程最终产出（所有赛题通用验收标准）**：

| 产出项 | 要求 |
|---|---|
| 研究报告 | 正文 ≥ 8000 字 + 研究总结 |
| 算法代码 | 可复现、可演示 |
| 系统集成验证 | 集成进「智戎」规划系统 |
| 答辩 PPT | 20 分钟：汇报 + 视频演示 + 质询 |

**评分关键点**：是否集成进智戎系统、是否做出超出选题任务的创新点；个人得分 = 小组得分 × 贡献系数；答辩随机点名，防止搭便车。

## 2. 各赛题难度、技术路线与推荐

### 赛题①：基于 GraphRAG 的图记忆系统

**技术路线（含 PPT 演讲者备注中的细节）**：
1. **作战知识图谱构建**：实体类型对齐六类知识库（装备/平台/条令/战例/机构/地域/事件）；关系类型对齐作战业务（装备-(杀伤链环节：探测/跟踪/打击/评估)→目标、条令-(约束)→装备、战例-(使用)→装备）；LLM 抽取 + 规则词典辅助的 NER/RE 管线；对公共数据集建图（≥200 实体、≥100 关系）；图存储与可视化。
2. **实体锚定校验**：抽取出的实体必须与库内条目对齐校验，杜绝"库外实体"混入图——防编造从建图环节开始。
3. **图索引与检索算法**：微软 GraphRAG 式（社区检测+社区摘要+全局/局部检索）或 LightRAG 式（双层图+双层检索）；查询→种子实体→邻域扩展→证据聚合，输出带推理路径的检索结果。
4. **混合检索融合**：图路径证据与向量/稀疏 chunk 证据合并排序。
5. **评测**：与 TF-IDF 基线、纯向量 RAG 三路对比；重点分析多跳型/全局综述型查询；消融实验（去社区摘要/去邻域扩展）；构建成本与检索时延报告（为 30 秒内重算突防航线留时延预算）。

**难度评估**：★★★★☆（中上）
- 图谱构建工程量大：NER/RE 管线、schema 设计、实体对齐校验都要自己做；
- GraphRAG/LightRAG 有开源项目可参考，但需要读懂并改造；
- 需要 Neo4j/NetworkX 等图技术，学习曲线较陡；
- 亮点明显：推理路径天然支持溯源，与"知识锚定"约束契合。

**适合人群**：对图、知识图谱有兴趣，愿意啃 GraphRAG 源码的同学。

### 赛题②：多模态记忆系统（你的倾向）

**技术路线**：
1. **多模态规划知识构建**：整理表/MD/PDF/图像四类知识的标注与组织方式；
2. **多模态解析入库**：PDF 拆解出文本/表格/图片，表格和图片分别结构化、描述化；
3. **模态无关的记忆索引与检索**：把文本、表格、图片映射到统一向量空间（或统一检索接口），用自然语言查询跨模态召回；
4. **检索内容增强作战规划 + 实验分析与系统集成验证**。

**难度评估**：★★★☆☆（中等，最适合入门进阶）
- 每个子模块都有成熟开源方案（CLIP/SigLIP、BGE、Chroma、Unstructured 等），不会"卡死在某一环节"；
- 难点集中在**表格结构保留**与**图片语义提取**，有明确的量化指标可验证；
- 创新空间大：双通道编码、模态路由、领域对齐微调、溯源解释等都能做出增量贡献；
- 与课程主线（异构多模态数据环境）最直接对应。

**适合人群**：AI 刚起步、想快速做出可演示系统、并留出余力做创新点的同学（强烈推荐）。

### 赛题③：长短期记忆系统

**技术路线**：
1. **短期/工作记忆层**：会话内上下文管理、意图与中间结果暂存；
2. **长期记忆层**：跨会话经验固化、摘要沉淀、语义索引；
3. **记忆更新机制**：写入策略、合并去重、动态更新与遗忘（衰减/淘汰）；
4. **记忆检索调用**：按需调取历史经验注入规划；
5. 检索内容增强作战规划 + 实验分析与系统集成验证。

**难度评估**：★★★★★（最高）
- 涉及记忆写入/读取/遗忘的完整生命周期设计，缺少单一成熟开源方案；
- 与智能体框架、会话管理耦合深，调试和评估都困难；
- "遗忘机制"难量化验证，容易做出"演示好看、指标模糊"的结果；
- 若做深（MemGPT/Letta、生成智能体记忆流、反射机制）学术上限很高。

**适合人群**：对智能体架构有经验、想挑战硬核方向的同学；不建议零基础首选。

### 赛题④：记忆系统评估

**技术路线**：
1. **测试集**：构造覆盖文本/表格/图片/跨文档多跳的统一测试集；
2. **评测指标**：四层指标体系（预计为数据层、检索层、记忆层、任务层或类似分层）；
3. **评测框架**：自动化打分 + 交叉盲测；
4. 实验分析与系统集成验证。

**难度评估**：★★☆☆☆（工作量偏"广度"）
- 技术门槛相对低，主要是工程化：写测试集、跑评估、做统计；
- 但"被评估对象"依赖其他赛题的系统，进度受制于人，交叉盲测组织成本高；
- 创新上限有限，容易被老师问"你自己的系统在哪"；
- 优点是成果可直接服务全课程，小组协作价值大。

**适合人群**：喜欢严谨实验设计、愿意承担公共基础设施角色的同学。

### 2.4 2人团队 × 2-3周条件下的重新排序

**最终排序：② > ④ > ① > ③**

| 排名 | 赛题 | 2人 × 2-3周 下的判断 |
|---|---|---|
| 1 | ②多模态记忆 | 两条并行支线刚好对应两个人；代码包复用率最高；3天可见第一个里程碑 |
| 2 | ④评估 | 若与②组搭档（你们出系统、评估组出基准）其实很顺；但单组独立做会"等米下锅" |

## 3. 推荐结论：最终选定赛题③（长短期记忆系统）

> 更新说明：本文档早期分析曾推荐 **赛题②（多模态记忆系统）**，理由是"稳过验收、演示直观、零基础友好"。经进一步研究《03-记忆系统关键技术-长短期记忆+记忆系统评估.pdf》，并结合"规划 → 查询列表 → 检索 → 长期/短期记忆（记忆进化）"的系统设想，**最终改选赛题③**。赛题②完整方案保留在 `02_赛题二多模态记忆系统完整方案.md` 作为备选预案与对照。

### 3.1 为什么最终选赛题③

1. **学术本义最贴近课程主线**：赛题③直接回答"智能体如何记住并复用经验"，是四个赛题中最像"记忆系统"本义的方向；
2. **理论抓手充足**：讲义《长短期记忆 & 记忆评估》给出了 TiM / SCM / MemGPT / ChatDB / MIRIX / RMM / PREMem / LongLLMLingua / StructMem / MemSkill 等十多个可借鉴方法，短期记忆、长期记忆、检索、进化四个环节都有论文可对标（详见 `03`、`04` 文件）；
3. **你的系统设想天然分层**："规划 → 查询列表 → 检索 → 长期/短期记忆（记忆进化）"正好把**记忆检索**与**记忆进化**解耦，与讲义"记忆检索 / 记忆进化"两阶段一一对应，叙事完整、可独立评估；
4. **与智戎 AFSIM 对抗推演闭环强绑定**：作战规划既需要"当前任务工作记忆"（本次规划上下文与中间结果），也需要"跨场次经验记忆"（历史推演的经验教训），长短期记忆是可解释、可演示的刚需。

### 3.2 赛题③的系统定位（一句话）

为智戎作战规划智能体构建**可演化的外部记忆系统**：短期（工作）记忆支撑"当前规划内的上下文与中间结果"，长期记忆沉淀"跨任务的事实与经验"，通过**记忆检索**按需供给，通过**记忆进化**完成写入/合并/遗忘/抽象。

### 3.3 核心流程（对齐你的设想）

```
规划（意图理解 · 任务分解）
   → 查询列表（明确需要哪些知识/经验，形成检索计划）
   → 检索（任务感知查询 → 短期/长期记忆库 → 返回相关记忆 m_t）
   → 长期/短期记忆（工作记忆装载 + 长期记忆进化：写入/合并/遗忘/抽象）
   → 反馈闭环（规划结果评估 → 沉淀为新经验）
```

### 3.4 风险与对策

- **风险 1：短期/长期两层与"记忆进化"耦合深、调试难** → 把四个环节做成独立模块、独立评测（见 `04` 分模块技术路线）；
- **风险 2："遗忘机制"难量化** → 用讲义第 20 节的指标（跨任务迁移、时间敏感记忆、事件时序一致性等）与消融实验量化；
- **风险 3：2–3 周可能只做出"会话摘要级"演示** → 用 `04` 的降级预案，保底交付"工作记忆 + 长期事实/经验记忆 + 检索"端到端链路。
