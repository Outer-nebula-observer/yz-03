## 二、demo 输出逐段解读（照此讲"有效"）

`python examples/demo_pipeline.py` 跑两场闭环，关键输出与讲解词：

### 场次 P001：夜间夺占 2 号高地

**输出 ①：检索命中（带溯源）**
```
{'id': 'fact-9a96bd38', 'type': 'fact', 'score': 1.07, 'route': 'vector',
 'content': '2 号高地海拔 320 米，北坡缓南坡陡，仅东侧可装甲通行',
 'provenance': {'source': '', 'session_id': '', 'recall_count': 1}}
{'id': 'experience-0bcb35d5', 'type': 'experience', 'score': 0.70, 'route': 'bm25',
 'content': '教训：夜间行军未派先遣侦察，先头在隘口遭伏击', ...}
```
> **讲**：查询列表问"2 号高地地形通行"，命中地形事实（vector 路，分 1.07）；问"夜战教训"命中历史教训（bm25 路，分 0.70）——**三路混合检索各司其职，每条结果带 source/session_id/timestamp 可溯源（创新点 E）**。

**输出 ②：进化报告**
```
write: 1        ← 复盘文本里"电子压制/预备队"教训被抽取入库
skip_duplicate: 0
库规模：事实 2 / 经验 2
```
> **讲**：场次结束后的复盘文本（"教训：夜间突袭未前置电子压制…"）被进化模块自动抽取为**新经验记忆**写入——⑦ 记忆进化闭环工作。

### 场次 P002：夜间进攻 3 号高地（核心证据）

**输出 ③：第一场刚沉淀的记忆被第二场召回**
```
{'id': 'experience-b051149e', 'score': 0.60, 'route': 'vector',
 'content': '复盘：任务部分达成。教训：夜间突袭未前置电子压制，接敌后通信被干扰…',
 'provenance': {'source': '复盘:P001', 'session_id': 'P001', ...}}
```
> **讲（重点）**：这条记忆 `source='复盘:P001'`——**是 P001 场次刚沉淀的教训，在 P002 场次被检索召回并注入规划上下文**。这就是"可演化外部记忆"的核心价值：**智能体跨场次变强，且能指出"凭什么"（溯源到 P001）**。

**输出 ④：两场统计**
```
P001: {'retrieved': 3, 'loaded': 3, 'compressed': 0}
P002: {'retrieved': 4, 'loaded': 4, 'compressed': 0}
```
> **讲**：P002 检索到 4 条（P001 是 3 条）——多出的正是第一场新沉淀的经验，**库在增长、召回在变多**。

## 三、消融输出解读（量化"每个模块的贡献"）

`python -m eval.ablation` 输出（实跑数据）：

```
G0 无记忆基线   → 检索指标不适用（纯 LLM 对照组）
G1 仅短期       → store_size=6（链路通，检索旁路）
G2 +事实库      → hit@5=1.0  mrr=1.0  ndcg@5=1.0
G3 +经验库      → hit@5=1.0（双库全开）
G4 +进化        → store_size: 6 → 7   ← 进化真的沉淀了新记忆
G5 检索策略对比 → by_route: vector=1.0, bm25=1.0, sql=1.0
```

| 组 | 看什么 | 讲解词 |
|---|---|---|
| **G2→G3** | 检索指标 | 加入经验库后经验类查询可命中（本种子集事实/经验查询分列） |
| **G4** | **store_size 6→7** | "进化模块让记忆库增长"的**直接量化**——这就是 G4 消融的意义 |
| **G5** | by_route | 三条检索路各自 hit@5=1.0——混合检索没有短板路径 |

> **诚实说明（被追问必答）**：种子测试集仅 3 例 + MockEmbedding，指标全 1.0 **不能外推真实效果**，只证明链路正确。接真 embedding + 扩到 ≥40 条作战测试集（docs/04 5.2）后，这些数字才有区分度——**这正是下一步**（见第五节）。

## 五、"有效"的完整论证链（汇报一句话版）

> **链路有效**：七步闭环（规划→查询→检索→装载→输出→反馈→进化）离线全跑通，冒烟 7/7。

> **核心卖点**：**P001 复盘沉淀的教训被 P002 召回注入上下文——跨场次变强有实证、可溯源。**
> **量化框架就绪**：G0–G5 消融 + hit/recall/mrr/ndcg 指标已跑通；当前种子集指标全 1.0 属预期（Mock 组件+小测试集），接真模型后数字才用于结论。

ctl = MemoryController(llm=llm, embedding=emb,
                       factual=FactualStore("facts.db", emb),
