|---|---|
| `01_赛题分析与选题推荐.md` | 课程概览、四赛题分析、最终选题③ |

## 建议阅读顺序

```
01（了解课程与选题）→ 03（记忆理论 + 论文）→ 04（赛题③技术路线）
                                    →（需要多模态对照时）02
```

## 约定

- 文档内互相引用时使用相对文件名，例如 `04_赛题三长短期记忆系统完整方案.md`；
- 新文档建议沿用 `序号_标题.md` 命名，数字保持阅读顺序；
- 与课程资料的原始文件放 `../course_materials/`，不要混入本目录。
